# Reference: example-skill

This is a **supporting file** for `example-skill`. Skills can split long reference
material, lookup tables, or detailed specs into separate files like this one. The main
`SKILL.md` stays short; Claude loads this file only when it needs the detail.

Put things here such as:

- Long API/schema references
- Naming tables or enums
- Edge-case rules that would bloat the main skill

Delete this file if your skill doesn't need it.

# Lessons

The self-improvement loop from `AGENTS.md` §8: after **any** user correction, record
the pattern here as a rule that prevents the repeat. Agents skim this file at the
start of each session — newest first, so recent corrections are seen first.

Keep entries to three lines. If a lesson stops being relevant (the code or convention
changed), delete it; a long stale list stops being read. A lesson that keeps
mattering probably belongs in `AGENTS.md` or `ai/context/conventions/` — promote it
and remove it from here.

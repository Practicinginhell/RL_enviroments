# src/ — Application Code

Placeholder anchor for your code. Rename or restructure freely to match your stack —
`app/` for a web framework, `lib/` for a library, `packages/*/src/` for a monorepo,
`notebooks/` + `src/` for ML work. The template imposes no layout on your code, only
on the knowledge *around* it.

When you restructure, update the two places agents learn the layout from:

1. The **Repository Map** table in [AGENTS.md](../AGENTS.md)
2. The **Components** table in [ai/context/architecture.md](../ai/context/architecture.md)

Delete this file once real code lands.
